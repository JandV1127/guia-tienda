# 🏪 Gestor de Tienda NYJ

## Demo del sistema de gestión empresarial

Gestor de Tienda NYJ es una plataforma diseñada para ayudar a pequeños y medianos negocios a organizar y administrar sus principales procesos comerciales.

Esta versión corresponde a una **demo visual de presentación** del software.

---

## 🚀 Módulos disponibles

La demo presenta diferentes módulos del sistema:

- 📊 Dashboard
- 📦 Gestión de productos
- 💰 Gestión de ventas
- 👥 Gestión de clientes
- 🚚 Gestión de proveedores
- 📈 Reportes
- 🎧 Centro de soporte

---

## 🎯 Objetivo

El objetivo del Gestor de Tienda NYJ es facilitar la administración de negocios mediante una interfaz moderna, organizada y sencilla de utilizar.

La plataforma permite visualizar información relacionada con:

- Ventas
- Inventario
- Clientes
- Proveedores
- Reportes
- Indicadores del negocio

---

## ⚠️ Importante

Esta versión es únicamente una **demo de presentación**.

Los datos mostrados dentro de la plataforma son ficticios y las acciones realizadas dentro de la demo no representan operaciones comerciales reales.

No se utiliza una base de datos para esta versión.
